Importar alunos

O arquivo é lido e gravado direto no banco deste servidor — não passa pelo código do sistema nem pelo GitHub em nenhum momento. Depois de importado, o arquivo enviado é apagado do servidor automaticamente.

Lista de alunos — formato PILOTO

Planilha exportada do sistema de matrícula da rede (colunas Código, RA Prodesp, Nome do Aluno, Série, ...).

Se o arquivo original for .xls (formato antigo), abra no Excel/LibreOffice e use "Salvar como" → .xlsx antes de enviar.

Turma de projeto — "Alunos da Turma" do SGP

Relatório de uma turma de projeto (ex: PAP, Aprender e Ensinar). A turma vem das linhas do topo: Turma + Descrição e o Turno (sem a duração).

Pode enviar o .xls do SGP do jeito que ele vem. Diferente da lista PILOTO, a turma regular dos alunos não muda: a turma de projeto aparece em Início → Turmas → Projetos. Importar a mesma turma de novo atualiza a lista.

Lista de alunos — formato simplificado (com AEE junto)

Planilha com colunas Turno, Turma, Nome do Aluno, Filiação 1, Data Nascimento, RA, Código, Data Matrícula, AEE — tudo em uma aba só.

Identificação AEE (só para o formato PILOTO)

Planilha separada de AEE — o cruzamento é feito pelo código do aluno. Importe a lista de alunos PILOTO antes desta.

Fotos em lote

Envie várias fotos de uma vez — o sistema casa cada arquivo com o aluno certo pelo nome do arquivo.
